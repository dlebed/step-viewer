STEP Viewer — offline viewer for STEP / IGES / BREP CAD files with measurement tools.

Usage: double-click step-viewer.html (Chrome, Edge or Firefox). Drop a file on the
window or press Open. Nothing is installed and files never leave your computer.

Keep the vendor/ folder next to step-viewer.html.
To install it as an app (works offline, opens .step files from the OS), serve the folder
over http (for example: node serve.mjs) and click Install in Chrome or Edge.
Project page: https://github.com/dlebed/step-viewer
